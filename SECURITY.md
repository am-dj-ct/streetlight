# Security Policy

## Supported Versions

Access Tool is currently pre-1.0. Security fixes are applied on `main` and
deployed to the production alias.

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected security issues.

Report privately by email:
- `jesse.c.dunn@outlook.com`

Include:
1. What you found
2. Steps to reproduce
3. Impact
4. Any logs or screenshots that do not include user conversation content

## Response Targets

- Initial acknowledgement: within 72 hours
- Triage decision: within 7 days
- Public incident note timing: severity-based, per the incident framework in
  [docs/data_architecture.md](docs/data_architecture.md)

## Scope Notes

Please avoid including real user conversation text in reports. Synthetic
reproduction is preferred for this project.
