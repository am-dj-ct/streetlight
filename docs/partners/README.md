# Partner Materials

These are the builder-to-partner documents for soft launch and early
operations.

## Files

- `bug-report.md` — structured no-content issue intake for frontline staff.
- `current-limits.md` — plain-language limits to share before live use.
- `launch-packet.md` — ready-to-send partner intro packet.
- `launch_checklist.md` — builder-side checklist before a partner starts
  sending real people.
- `one-sentence-framing.md` — short approved ways to describe the tool.
