# Partner Launch Packet

Use this when a named partner is about to start sending real people to the
tool.

## What to send

1. The main URL
2. A one-sentence description
3. The current limits note
4. The bug-report template
5. The crisis reminder

## Ready-to-send version

You can copy this and edit the URL line.

> Streetlight URL: `https://streetlight.help`
>
> Streetlight is a free mobile-web AI helper for people under housing,
> benefits, or paperwork stress, with built-in links to real human help.
>
> A few current limits:
>
> - it can still be wrong, vague, or miss context
> - it is not a lawyer, clinician, case manager, or crisis line
> - some non-English wording may still read awkwardly or miss nuance
> - the tool may pause for a while if something looks wrong or if the daily
>   usage limit is reached
>
> If something seems wrong, confusing, unsafe, or broken, please use the
> bug-report template in `docs/partners/bug-report.md` and paraphrase instead
> of pasting the user's conversation.
>
> If someone needs urgent help right now: 988 for crisis, 211 for resources,
> 911 for emergencies.
