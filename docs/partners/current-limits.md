# Current Limits

Send or paraphrase this for partners before they start using the tool with real
people.

## Plain-language version

- The tool can still be wrong, vague, or miss context.
- It is not a lawyer, clinician, case manager, or crisis line.
- It should not be the only thing someone relies on for a high-stakes choice.
- The human-help list is maintained by hand, but the AI reply itself can still
  make mistakes.
- Some non-English wording may still read awkwardly or miss nuance.
- The tool may pause for a while if something looks wrong or if the daily usage
  limit is reached.

## Reporting problems

- Partners should paraphrase issues instead of pasting user conversations.
- Use `docs/partners/bug-report.md`.

## Crisis reminder

If someone needs urgent help right now:

- `988` for crisis
- `211` for resources
- `911` for emergencies
