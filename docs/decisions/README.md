# Architecture Decision Records

One markdown file per major decision. Each file records: the question,
options considered, the decision, the reasoning, and the date.

Filename convention: `YYYY-MM-DD-shortname.md`.

A future Claude Code session, contributor, or future-self should open the
relevant ADR before changing related things. ADRs are append-only —
superseded decisions stay in place, with a follow-up ADR linking to the
prior one.

The ten trigger conditions in `docs/data_architecture.md` require a dated
ADR before the change lands.
